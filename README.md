# 实时基金买卖点监控（分时做T + 多角度分析 + 回测预测）

本地运行的小工具：Python 数据服务 + 网页。从东方财富/天天基金获取**实时估值、历史净值、场内分时分钟线**，在服务端完成全量计算，给出**每日买卖点建议 + 盘中做T信号 + 基于历史回测的预测参考**。

## 快速开始

```bash
cd fund-monitor
python server.py
```

浏览器打开 <http://127.0.0.1:8765>（仅 Python 标准库，零依赖）

> 请通过本地服务访问页面，不要直接双击 index.html —— 东财接口有跨域/风控限制，数据由服务中转。

## 三层信号体系

### 1. 日线级别（每日买卖点，评分 ±8）

| 角度 | 规则 | 打分 |
|---|---|---|
| 均线偏离 MA20 | ≤-3% → +2；(−3,−1.5%] → +1；≥+3% → −2；[+1.5,+3%) → −1 | ±2 |
| RSI(14) | ≤30 → +2；(30,40] → +1；≥70 → −2；[60,70) → −1 | ±2 |
| 布林带(20,2σ) | 跌破下轨 +1 / 突破上轨 −1 | ±1 |
| KDJ(9) J值 | ≤10 → +1 / ≥90 → −1 | ±1 |
| 当日估算涨跌 | ≤−2% → +1（逢跌加仓）/ ≥+3% → −1 | ±1 |
| 近3年净值分位 | ≤20% → +1 / ≥80% → −1 | ±1 |

总分 ≥+3 强烈买入 / +1~+2 买入 / 0 观望 / −1~−2 减仓 / ≤−3 强烈减仓，附具体操作建议。
另附观察项：MA排列、MACD多空、连续涨跌天数、60日区间位置、10日动量、量能对比、收益/波动/回撤统计。
日线图上 ▲▼ 标注历史信号点（滞回状态机：±2进入、回到0退出）。

### 2. 盘中级别（做T信号，分时图，实时更新）

- **场内基金（LOF/ETF）**：东财 push2his 分钟线（5日），分时图含现价线、均价线（VWAP）、昨收基准；每次刷新（10~30秒）全量重算当日信号
- **信号规则（全部为触发时刻的实时预测，仅用当时及之前的行情）**：
  1. **T买**：价格低于均价线 **1.5σ**（近60分钟偏离标准差）+ 近3分钟回升确认 + 基本量价配合（缩量或近15分主买≥55%，上涨分钟量估算主动买盘）
  2. **T卖（配对退出，每个T买必配对一个T卖，买卖交替）**：
     - 反弹至止盈价（买入价 + max(0.2%, 0.8σ)）且滞涨 → **反弹止盈**
     - 跌破止损价（买入价 − max(0.4%, 1.2σ)）→ **止损保护**（比买价低，是有意截断亏损，页面以琥珀色▼止损单独标识）
     - 14:57后仍持仓 → **尾盘平仓**（T+0纪律，不隔夜）
  3. **减仓卖点**（不配对）：上涨日冲高回落（偏离+1.5σ回落确认）；下跌日反弹至均价线滞涨
  - ★ = 量价资金共振强信号；T买后实时显示止盈/止损参考价；快照附当日状态提示（下行日提示谨慎做T）
- 做T面板：现价/均价线/偏离σ/**T买、T卖参考价**/**主买占比(全日/近15分)/量比**/高低/振幅/15分动量
- **场外基金**：无成交量维度，信号仅基于估值曲线（服务轮询自动累积）；分时入口始终可见，无数据时给出提示
- 提示：跨境ETF（如513060）支持 T+0；普通场内基金 T+1

### 每日买卖点表与参考价位

- **📅 每日买卖点表**：近16个交易日逐日列出 日期 / 净值 / 评分 / 信号（强买·买入·观望·卖出·强卖）/ **次日与5日后的实际涨跌（事后验证）**，最后一行为"今日"实时评分（盘中随估值更新）
- **📐 日线触发价**：买入触发价 = min(MA20×0.985, 布林下轨)，止盈触发价 = max(MA20×1.015, 布林上轨)（按单位净值口径），净值越过即触发对应信号

### 3. 预测参考（准确度量化，不是拍脑袋预测）

对**全部历史逐日回测**：当前信号所属类别（买入/卖出/观望）历史上出现 N 次时，其后 5日/20日 的真实表现：

- 方向一致胜率、平均涨跌
- 历史买卖点事件后5日方向正确率
- 置信度（高/中/低，依据样本量与胜率）；观望桶作为市场基准对照

> 过去表现不代表未来，数字仅供评估信号质量参考。

### 模拟持仓（纸面交易）

每只基金卡片可设置模拟仓位：**+ 建仓/加仓 / − 减仓**（价格自动按当前现价/净值预填，可改为实际成交价），自动计算：

- 持仓份额、**加权成本**、市值、总盈亏（金额+百分比）
- **当日盈亏**：份额 ×（现价 − 昨收）
- **昨日盈亏**：份额 ×（昨收 − 前日收盘）
- **今日已实现盈亏**：减仓/清仓锁定的收益（跨日自动清零）

仓位保存在浏览器本地，配合 T 信号可实现完整的模拟做T训练。

## 数据来源（仅供学习研究）

- 实时估值/基金信息：`fundmobapi.eastmoney.com/FundMNewApi/FundMNFInfo`（服务端调用，规避浏览器风控）
- 历史净值（单位/累计）：`fund.eastmoney.com/pingzhongdata/{code}.js`
- 场内分时：`push2his.eastmoney.com/api/qt/stock/trends2/get`

历史净值与回测按天缓存，估值15秒、分时20秒缓存，不会高频请求源站。东财部分接口对 Python 的 TLS 指纹有风控（连接被掐断），`http_get` 会在 urllib 失败时自动回退系统 curl（Windows 10+ 自带）。
